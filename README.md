# Babylon Racing

Браузерные гонки: девять персонажей, четыре трассы, дрифт, семь предметов и онлайн на двоих с семью ботами.

## Запуск по ссылке на Render

В репозитории есть и сама игра (`public/`), и сервер комнат. После успешного развёртывания достаточно открыть корневой адрес сайта: он направит на `/viewer/`.
Скачивать игру, устанавливать Python или Node.js игрокам не нужно. Первый запуск загружает модели и трассу; повторные загрузки используют кеш браузера.

Для существующего сервиса Render:

1. Подключённый репозиторий: `DudeRyry13/Race`, ветка `main`.
2. Runtime: Node; Root Directory — пусто.
3. Build Command: `npm ci && npm run build`.
4. Start Command: `npm start`.
5. Health Check Path: `/health`.
6. Выполнить Manual Deploy → Deploy latest commit, если автоматическое обновление выключено.
7. Открыть адрес сервиса, например [Babylon Racing](https://race-yx4w.onrender.com/).

Переустанавливать сервер или создавать новый сервис ради этой версии не требуется.
Если в старом сервисе осталась команда сборки `npm ci`, игра также запускается; команда выше дополнительно сжимает скрипты и данные для загрузки.
Порт берётся из `PORT`, по умолчанию 3000. Для своего домена можно задать `PUBLIC_URL`.

## Онлайн

Создатель открывает сайт, нажимает «Создать комнату» и отправляет приглашение. Друг открывает эту ссылку — игра сама присоединится к комнате.
Оба выбирают разных героев и нажимают «Готов». Создатель запускает заезд.

Физику и результаты считает браузер создателя. Игра пытается установить прямой WebRTC-канал; если это не удаётся, используется сервер WebSocket.
Индикатор показывает маршрут и задержку до второго игрока. Сглаживание камеры, траекторий и локальное предсказание помогают при задержках, но не снижают физический пинг.
Создатель должен держать вкладку открытой. Пауза общая; выход создателя закрывает комнату.

## Модели для веба

В `public/` находятся только актуальные модели. Исходники Blender и старые тяжёлые GLB не включены в репозиторий.
Модели подготовлены в Blender со сжатием Draco; декодер включён в игру и загружается с этого же сайта.
Сетка Сеттриха сохранена полностью, уменьшены текстуры. У трёх других тяжёлых моделей снижена плотность сетки; риг и все семь анимаций сохранены.
Лицензии Three.js и Draco находятся в `public/viewer/vendor/`.

## Управление

- WASD / стрелки — газ, тормоз и поворот.
- Пробел — турбо.
- Shift + поворот — дрифт, отпускание Shift даёт мини-турбо.
- E — предмет, Q — сбросить назад.
- C — камера, Esc — пауза, R — новый старт.

## Другой хостинг

Нужен Node.js 22 или новее с поддержкой HTTPS и WebSocket:

```sh
npm ci
npm run build
npm start
```

Локально: `http://127.0.0.1:3000/`. На сервере игра и API должны быть на одном адресе.
Сервер раздаёт только содержимое `public/`; исходники, конфигурация и зависимости через сайт не публикуются.

Render Free может засыпать после простоя; первый запрос тогда занимает больше времени.
Условия хостинга и лимиты трафика: [Render Free](https://render.com/docs/free).
Настройка деплоя: [Render Web Services](https://render.com/docs/web-services).
