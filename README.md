# Сервер комнат Babylon Racing

На сервер загружаются только файлы этой папки. Модели и трассы загружать не нужно.
Это сервер связи двух скачанных копий игры: два человека и семь ботов.
Физику и результаты считает игра создателя комнаты.

## Render

1. Создай репозиторий GitHub и добавь файлы этой папки.
2. На render.com выбери New → Web Service и подключи этот репозиторий.
3. Runtime: Node. Instance Type: Free.
4. Build Command: `npm ci`. Start Command: `npm start`.
5. После развёртывания получишь адрес вида `https://имя-сервера.onrender.com`.
6. Вставь его в «Адрес своего сервера» в игре, нажми «Создать комнату».
7. Скопируй ссылку комнаты и отправь другу. Друг вставляет её в поле приглашения.
8. Выберите разных героев, оба нажмите «Готов», затем создатель запускает заезд.

Render Free засыпает после 15 минут без входящего трафика; первый запуск после простоя может занять около минуты.
Условия: https://render.com/docs/free
WebSocket: https://render.com/docs/websocket

## Другой сервер с Node.js

Нужен Node.js 22 или новее. Команды:

```sh
npm ci
npm start
```

Порт берётся из `PORT`, по умолчанию 3000. Публичный адрес можно задать в `PUBLIC_URL`.
Внешний адрес должен быть HTTPS с поддержкой WebSocket.
Локальная проверка: `http://127.0.0.1:3000`.
Node.js нужен только на сервере. У игроков запуск как раньше, через START_DRIVING.cmd.
