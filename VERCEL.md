# Babylon Racing на Vercel

На Vercel размещается сама игра: меню, код, модели, трассы, картинки и музыка.
Комнаты и WebSocket-соединения обслуживает текущий сервер https://race-yx4w.onrender.com.
Приглашение открывает игру на Vercel и хранит адрес сервера комнат в части ссылки после `#`.

## Публикация из GitHub

1. Открой https://vercel.com/new и импортируй `DudeRyry13/Race`.
2. Root Directory оставь пустой, Framework Preset — Other.
3. Настройки берутся из `vercel.json`: сборка `npm run build:vercel`, результат `dist-vercel`.
4. Нажми Deploy. После завершения открой выданную ссылку `https://имя-проекта.vercel.app/`.

Дополнительные программы игрокам не нужны. Никакие платные функции или базы данных
эта конфигурация не создаёт. Для смены сервера комнат задай переменную сборки
`ONLINE_SERVER_URL` с его HTTPS-адресом и запусти новую сборку.

Используй импорт GitHub: сборка игры больше 100 МБ, а для загрузки исходников
через CLI у бесплатного тарифа Vercel есть отдельный лимит 100 МБ.

## Сервер комнат

Эта конфигурация не переносит сервер комнат на Vercel. Сейчас он хранит комнаты
и подключения в памяти одного процесса. Vercel Functions могут распределить
соединения по разным экземплярам и закрывают их по ограничению времени работы.
Для размещения комнат там нужны общее хранилище, доставка сообщений между
экземплярами и восстановление подключений.

Доступ из России зависит от провайдера. Наличие ссылки `.vercel.app` не даёт
гарантии доступности во всех сетях. Пока сервер комнат остаётся на Render,
доступ к нему также нужен для сетевой игры.
