# Temporary Babylon Racing soundtrack

**Monkeys Spinning Monkeys** — Kevin MacLeod (incompetech.com).

Source: https://incompetech.com/music/royalty-free/index.html?isrc=USUAN1400011
Download: https://incompetech.com/music/royalty-free/mp3-royaltyfree/Monkeys%20Spinning%20Monkeys.mp3
License: Creative Commons Attribution 4.0, https://creativecommons.org/licenses/by/4.0/

The original MP3 is included as `race-theme.mp3`. The game loops it and controls playback volume; the audio file itself has not been edited. Credit and license links are shown in the game menu.

Engine, gear shifts, tyres, wind, turbo, collisions, weapons, pickups, countdown and finish effects are generated by the project's own Web Audio code in `viewer/race-audio.mjs`.
